旅遊團號：`CTS05IT26D22K01`  
旅遊日期：2026-12-22 至 2026-12-26  
網站：<https://chiraytsai.github.io/cr-travel/>

## 目前版本

**V1.3｜溫暖聖誕主題・純靜態 GitHub Pages 網站**

以「白色聖誕・溫暖旅程」為視覺主題，採奶油白、聖誕紅、松針綠與暖金色；首頁使用 SVG 暖光雪景插畫，搭配簡潔的旅遊卡片。

## 五個主選單

1. **今日**：旅行倒數、當日重點、行程與工具捷徑。
2. **行程**：2026/12/22–12/26 五天路線、景點介紹、自由活動標示與 Google Maps 查詢。
3. **工具**：日圓／台幣雙向換算、Google 翻譯捷徑、六句日語放大卡片、行程城市天氣查詢、日本與台灣時間對照、飯店日文地址卡（待確認）。
4. **清單**：行前待辦，使用瀏覽器本機儲存，不跨裝置同步。
5. **資訊**：航班、行李、飯店與領隊待確認事項、緊急資訊。

## 已移除功能

- 已將原「購物」分頁改名為「工具」。
- 已移除購物紀錄、購物總額、消費統計與伴手禮想買清單的畫面及程式。
- 網站不使用 Google Sheets、Apps Script、Firebase 或其他雲端資料庫，也不要求 Google 帳號登入。
- 已移除先前 GitHub 專案內的 Apps Script 原始碼及部署教學。
- 原瀏覽器的舊版購物紀錄仍可能存在於舊的 localStorage 項目中，但**新版不讀取、不顯示、不上傳，亦不主動刪除**；行前清單和匯率偏好可沿用舊版紀錄。

## 網站運作與限制

- GitHub Pages 靜態網站部署於 `main` 分支根目錄。
- 換匯參考匯率透過 [Frankfurter API](https://frankfurter.dev/) 取得，並非即時成交匯率，讀取失敗可自行輸入。
- 翻譯使用 Google 翻譯外部網站；天氣按鈕開啟外部查詢，日本氣象廳為官方預報入口。即時翻譯或即時天氣需連線；日語句卡是本網站的靜態內容。
- 日台時間以裝置時鐘及 `Intl.DateTimeFormat` 計算，日本比台灣快一小時。
- 行前清單與手動匯率設定僅儲存於**目前裝置的目前瀏覽器**；清除網站資料、使用無痕視窗或換手機可能造成紀錄遺失。
- 飯店、領隊及集合資訊未獲正式通知前維持「待確認」，不填入未經確認的資訊。
- 函館聖誕嘉年華、洞爺湖燈光隧道及札幌聖誕市集為自由活動選項，非旅行社保證景點。小樽運河為行程途經，非保證下車。
- 之前建立的 Google 試算表及已部署的 Apps Script 不受 GitHub 修改影響；**如不再使用公開 Apps Script，仍須由其擁有者自行至 Apps Script 後台封存部署**。
